# Domain glossary

## Main Game

A member's preferred game. Choosing a Main Game does not establish a character, a game role, or Black Rose membership for that game.

## Game Profile

The information a member maintains for one game: their primary character or in-game identity, game-specific role, and any optional details configured for that game. A saved profile is not proof of guild membership.

## Game Membership

An explicitly recorded relationship between a member and Black Rose for one game. Its states are Interested, Applying, Accepted, Inactive, and Left. It is independent of Main Game and Discord verification.

## Accepted Member

A member whose membership for a specific game has been accepted by an administrator. Members cannot accept their own applications.

## Game Role

A member's gameplay responsibility or position for a particular game, chosen from that game's configured role options. It is not an application permission or administrative role.

## Character Class

An optional game-specific character archetype. It is separate from gameplay role; a class may imply a role in a game, but the application does not infer one automatically.

## Shared Game Identity

An account identifier shared by related games, such as a Riot ID. Sharing an identifier does not mean that its owner plays, has applied to, or belongs to Black Rose in every related title.

## Retired Configuration

A game or option that is no longer offered for new selections. Existing saved information remains historical information rather than being silently deleted.
